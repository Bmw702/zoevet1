# Zoevet Frontend Prototype

Frontend implementation based on the supplied Zoevet UI reference.

## Included
- Customer e-commerce homepage
- Product listing + filters
- Product details
- Cart
- Checkout
- Payment
- Order success
- Order tracking
- My Account
- Doctor registration
- Doctor dashboard
- Research submission details
- Public doctor profile
- Admin dashboard

## Run
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Main routes
- `/store`
- `/products`
- `/products/petvit`
- `/cart`
- `/checkout`
- `/payment`
- `/order-success`
- `/tracking`
- `/account`
- `/doctor`
- `/doctor/register`
- `/doctor/submission`
- `/doctor/profile`
- `/admin`

The local images in `public/images` are crops from the supplied reference image and are intended as visual placeholders for the prototype. Replace them with final product/brand assets before production.
